# 设计方案补充 - 移动端设计说明

## 1. 移动端设计概述

### 1.1 技术栈

**项目**: et_uniapp

**技术**: 
- uni-app（跨平台框架）
- Vue 2
- uni-ui（组件库）
- vuex（状态管理）

**支持平台**:
- H5
- 微信小程序
- APP（iOS/Android）

### 1.2 设计原则

**与PC端的关系**:
- **业务逻辑相同**: 商品展示、意向清单、询价流程与PC端完全一致
- **UI适配不同**: 针对移动端屏幕尺寸和交互方式优化
- **API接口相同**: 使用相同的后端API接口
- **多语言方案相同**: 使用相同的多语言实现方案

**移动端特点**:
- 单列布局为主
- 底部Tab导航
- 下拉刷新、上拉加载
- 触摸手势交互
- 适配不同屏幕尺寸

## 2. 移动端与PC端的差异

### 2.1 布局差异

| 功能模块 | PC端 | 移动端 |
|---------|------|--------|
| 导航 | 顶部横向导航栏 | 底部Tab导航 |
| 商品列表 | 网格布局（3-4列） | 单列或双列布局 |
| 商品详情 | 左右分栏 | 上下滚动 |
| 意向清单 | 表格布局 | 卡片列表 |
| 询价表单 | 单页表单 | 分步表单（可选） |
| 用户中心 | 侧边栏菜单 | 列表菜单 |

### 2.2 交互差异

| 交互方式 | PC端 | 移动端 |
|---------|------|--------|
| 图片预览 | 鼠标悬停 | 点击放大 |
| 下拉菜单 | 鼠标点击 | 触摸展开 |
| 分页 | 页码分页 | 上拉加载更多 |
| 搜索 | 顶部搜索框 | 独立搜索页面 |
| 语言切换 | 下拉选择 | 弹出选择器 |

### 2.3 组件差异

| 组件 | PC端 | 移动端 |
|-----|------|--------|
| 表格 | el-table | 卡片列表 |
| 对话框 | el-dialog | uni-popup |
| 选择器 | el-select | picker |
| 日期选择 | el-date-picker | picker-view |
| 上传 | el-upload | uni.chooseImage |

### 4.2 语言切换组件

```vue
<!-- components/language-switcher/index.vue -->
<template>
  <view class="language-switcher" @click="showPicker">
    <text>{{ currentLanguageName }}</text>
    <uni-icons type="arrowdown" size="16" />
  </view>
</template>

<script>
export default {
  data() {
    return {
      languages: [
        { label: '中文', value: 'zh' },
        { label: 'English', value: 'en' },
        { label: 'Русский', value: 'ru' },
        { label: 'العربية', value: 'ar' }
      ]
    }
  },
  computed: {
    currentLanguage() {
      return this.$i18n.locale
    },
    currentLanguageName() {
      const lang = this.languages.find(l => l.value === this.currentLanguage)
      return lang ? lang.label : 'Language'
    }
  },
  methods: {
    showPicker() {
      uni.showActionSheet({
        itemList: this.languages.map(l => l.label),
        success: (res) => {
          const lang = this.languages[res.tapIndex]
          this.changeLanguage(lang.value)
        }
      })
    },
    changeLanguage(lang) {
      this.$i18n.locale = lang
      uni.setStorageSync('language', lang)
      
      // 设置RTL
      if (lang === 'ar') {
        // 阿拉伯语RTL处理
        // uni-app中需要通过CSS处理
      }
      
      this.$emit('change', lang)
      
      // 提示用户
      uni.showToast({
        title: this.$t('message.success'),
        icon: 'success'
      })
    }
  }
}
</script>
```

### 5.1 商品列表页面（移动端）

```vue
<!-- pages/goods/list.vue -->
<template>
  <view class="goods-list-page">
    <!-- 搜索栏 -->
    <view class="search-bar">
      <uni-search-bar
        v-model="keyword"
        :placeholder="$t('common.searchPlaceholder')"
        @confirm="handleSearch"
      />
    </view>

    <!-- 商品列表 -->
    <view class="goods-list">
      <view
        v-for="item in list"
        :key="item.id"
        class="goods-item"
        @click="goDetail(item.id)"
      >
        <image :src="getProductImage(item)" mode="aspectFill" />
        <view class="goods-info">
          <text class="goods-name">{{ getProductName(item) }}</text>
          <text class="goods-desc">{{ getProductDesc(item) }}</text>
          <view class="goods-price">
            <text class="price-cny">¥{{ item.price }}</text>
            <text class="price-usd">/ ${{ item.priceUsd }}</text>
          </view>
          <view class="goods-actions">
            <button size="mini" @click.stop="addToCart(item)">
              {{ $t('common.addToCart') }}
            </button>
            <button type="primary" size="mini" @click.stop="inquiryNow(item)">
              {{ $t('common.inquiryNow') }}
            </button>
          </view>
        </view>
      </view>
    </view>

    <!-- 加载更多 -->
    <uni-load-more :status="loadStatus" />
  </view>
</template>

<script>
export default {
  data() {
    return {
      keyword: '',
      list: [],
      pageNum: 1,
      pageSize: 10,
      loadStatus: 'more' // more/loading/noMore
    }
  },
  onLoad(options) {
    if (options.keyword) {
      this.keyword = options.keyword
    }
    this.loadData()
  },
  onPullDownRefresh() {
    this.pageNum = 1
    this.list = []
    this.loadData()
  },
  onReachBottom() {
    if (this.loadStatus === 'more') {
      this.pageNum++
      this.loadData()
    }
  },
  methods: {
    async loadData() {
      this.loadStatus = 'loading'
      try {
        const res = await this.$api.getProductList({
          keyword: this.keyword,
          pageNum: this.pageNum,
          pageSize: this.pageSize
        })
        
        if (this.pageNum === 1) {
          this.list = res.data.list
        } else {
          this.list = [...this.list, ...res.data.list]
        }
        
        this.loadStatus = res.data.hasNextPage ? 'more' : 'noMore'
        
        uni.stopPullDownRefresh()
      } catch (error) {
        this.loadStatus = 'more'
        uni.showToast({
          title: this.$t('message.failed'),
          icon: 'none'
        })
      }
    },
    
    getProductName(item) {
      const langMap = {
        zh: item.storeName,
        en: item.storeNameEn,
        ru: item.storeNameRu,
        ar: item.storeNameAr
      }
      return langMap[this.$i18n.locale] || item.storeName
    },
    
    getProductImage(item) {
      const langMap = {
        zh: item.image,
        en: item.imageEn,
        ru: item.imageRu,
        ar: item.imageAr
      }
      return langMap[this.$i18n.locale] || item.image
    },
    
    goDetail(id) {
      uni.navigateTo({
        url: `/pages/goods/detail?id=${id}`
      })
    },
    
    addToCart(item) {
      // 添加到意向清单
      this.$store.dispatch('cart/addToCart', item)
      uni.showToast({
        title: this.$t('message.addToCartSuccess'),
        icon: 'success'
      })
    },
    
    inquiryNow(item) {
      uni.navigateTo({
        url: `/pages/inquiry/submit?productId=${item.id}`
      })
    }
  }
}
</script>
```

## 6. API请求封装

### 6.1 请求拦截器

```javascript
// utils/request.js
const baseURL = process.env.VUE_APP_BASE_API

// 请求拦截
function request(options) {
  // 添加token
  const token = uni.getStorageSync('token')
  if (token) {
    options.header = {
      ...options.header,
      'Authorization': 'Bearer ' + token
    }
  }
  
  // 添加语言标识
  const language = uni.getStorageSync('language') || 'zh'
  options.header = {
    ...options.header,
    'Accept-Language': language
  }
  
  return new Promise((resolve, reject) => {
    uni.request({
      url: baseURL + options.url,
      method: options.method || 'GET',
      data: options.data,
      header: options.header,
      success: (res) => {
        if (res.data.code === 200) {
          resolve(res.data)
        } else {
          uni.showToast({
            title: res.data.message,
            icon: 'none'
          })
          reject(res.data)
        }
      },
      fail: (err) => {
        uni.showToast({
          title: '网络错误',
          icon: 'none'
        })
        reject(err)
      }
    })
  })
}

export default request
```

## 7. 移动端特殊处理

### 7.1 图片上传

```javascript
// 移动端图片上传
chooseImage() {
  uni.chooseImage({
    count: 1,
    success: (res) => {
      const tempFilePath = res.tempFilePaths[0]
      this.uploadImage(tempFilePath)
    }
  })
}

uploadImage(filePath) {
  uni.uploadFile({
    url: baseURL + '/api/common/upload/image',
    filePath: filePath,
    name: 'file',
    header: {
      'Authorization': 'Bearer ' + uni.getStorageSync('token')
    },
    success: (res) => {
      const data = JSON.parse(res.data)
      if (data.code === 200) {
        this.imageUrl = data.data.url
      }
    }
  })
}
```

## 8. 移动端设计总结

### 8.1 与PC端的一致性

✅ **相同部分**:
- 业务逻辑完全一致
- API接口完全相同
- 数据结构完全相同
- 多语言方案相同
- 状态管理逻辑相同

### 8.2 移动端的特殊性

📱 **不同部分**:
- UI布局适配移动端
- 交互方式适配触摸
- 使用uni-app组件库
- 底部Tab导航
- 上拉加载更多
- 图片上传使用uni API

### 8.3 实现建议

**开发顺序**:
1. 先完成PC端开发和测试
2. 复用PC端的业务逻辑代码
3. 重点关注UI适配和交互优化
4. 测试不同平台（H5、小程序、APP）

**参考PC端设计**:
- 页面结构参考PC端
- 组件功能参考PC端
- API调用参考PC端
- 多语言处理参考PC端

**移动端优化**:
- 图片懒加载
- 列表虚拟滚动
- 缓存优化
- 性能优化

## 9. 注意事项

1. **跨平台兼容**: 注意H5、小程序、APP的差异
2. **性能优化**: 移动端性能要求更高，注意优化
3. **网络处理**: 移动端网络不稳定，做好错误处理
4. **用户体验**: 加载状态、错误提示要友好
5. **适配测试**: 测试不同屏幕尺寸和分辨率

---

## 10. 结论

移动端设计可以**完全参考PC端的设计文档**，主要差异在于：
- UI布局适配
- 组件库选择（uni-ui vs Element UI）
- 交互方式（触摸 vs 鼠标）

**核心业务逻辑、API接口、数据结构、多语言方案都与PC端保持一致**，因此不需要单独编写详细的移动端设计文档。

在实现阶段，可以边开发边补充移动端特有的设计细节。
