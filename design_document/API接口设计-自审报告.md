**问题描述**: 平台端没有系统配置管理接口（查询、更新）

**影响**: 平台无法修改系统配置（网站名称、SEO信息、联系方式等）

### 问题4：缺少图片上传接口
**问题描述**: 商家添加商品时需要上传图片，但没有图片上传接口

**影响**: 商家无法上传商品图片

**解决方案**: 需要补充图片上传接口（通用接口，C端、商家端、平台端都可以使用）

### 问题5：缺少站内消息接口
**问题描述**: 系统会发送站内消息通知商家（翻译完成、审核结果等），但没有站内消息接口

**影响**: 商家无法查看站内消息

**解决方案**: 需要补充站内消息接口（列表、详情、标记已读）

---

### 问题6：询价单详情权限问题
**问题描述**: C端用户查询询价单详情时，只检查了uid，但游客询价的uid为null

**影响**: 游客无法查看自己提交的询价单

**解决方案**: 
- 方案A：游客提交询价后返回一个查询码，游客可以通过查询码查询询价单
- 方案B：游客询价不支持查询，只有登录用户可以查询自己的询价单

---

### 问题7：意向清单商品失效处理
**问题描述**: 意向清单列表返回了isValid字段，但没有批量删除失效商品的接口

**影响**: 用户需要手动一个一个删除失效商品

**解决方案**: 需要补充批量删除意向清单商品的接口

---

### 问题8：商品列表缺少价格区间筛选

## 📋 需要补充的接口清单

### 高优先级（必须补充）

1. **图片上传接口** - POST /api/common/upload/image
2. **平台端分类管理接口** (4个)
   - GET /api/platform/category/list - 分类列表
   - POST /api/platform/category/add - 添加分类
   - PUT /api/platform/category/update/{id} - 更新分类
   - DELETE /api/platform/category/delete/{id} - 删除分类

3. **平台端商家管理接口** (4个)
   - GET /api/platform/merchant/list - 商家列表
   - GET /api/platform/merchant/detail/{id} - 商家详情
   - PUT /api/platform/merchant/update-status/{id} - 启用/禁用商家
   - POST /api/platform/merchant/add - 添加商家

4. **平台端系统配置管理接口** (2个)
   - GET /api/platform/config/list - 配置列表
   - PUT /api/platform/config/update - 更新配置

5. **站内消息接口** (3个)
   - GET /api/merchant/message/list - 消息列表
   - GET /api/merchant/message/detail/{id} - 消息详情
   - PUT /api/merchant/message/mark-read/{id} - 标记已读

### 中优先级（建议补充）

6. **密码修改接口** (3个)
   - PUT /api/front/user/change-password - C端用户修改密码
   - PUT /api/merchant/auth/change-password - 商家修改密码
   - PUT /api/platform/auth/change-password - 平台管理员修改密码

7. **批量删除意向清单接口** - DELETE /api/front/cart/batch-delete

8. **询价单导出接口** - GET /api/platform/inquiry/export

9. **翻译记录查询接口** (2个)
   - GET /api/platform/translation/record-list - 翻译记录列表
   - GET /api/platform/translation/record-detail/{id} - 翻译记录详情

### 低优先级（可选补充）

10. **游客询价查询接口** - GET /api/front/inquiry/query-by-code
