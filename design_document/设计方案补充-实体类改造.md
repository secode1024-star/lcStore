# 设计方案补充文档 - 实体类改造部分

## 问题1：StoreProductDescription实体类改造

### 现状分析
- 当前字段：id, product_id, description, type
- 缺少多语言字段

### 改造方案

#### 1.1 新增字段
```java
@ApiModelProperty(value = "商品详情-英文")
private String descriptionEn;

@ApiModelProperty(value = "商品详情-俄语")
private String descriptionRu;

@ApiModelProperty(value = "商品详情-阿拉伯语")
private String descriptionAr;

@ApiModelProperty(value = "翻译状态：0-未翻译，1-翻译中，2-翻译完成，3-翻译失败")
private Integer translationStatus;

@ApiModelProperty(value = "翻译错误信息")
private String translationError;

@ApiModelProperty(value = "最后翻译时间")
private Date lastTranslationTime;
```

#### 1.2 对应SQL
```sql
ALTER TABLE eb_store_product_description
ADD COLUMN description_en TEXT COMMENT '商品详情-英文',
ADD COLUMN description_ru TEXT COMMENT '商品详情-俄语',
ADD COLUMN description_ar TEXT COMMENT '商品详情-阿拉伯语',
ADD COLUMN translation_status TINYINT(1) NOT NULL DEFAULT 0 COMMENT '翻译状态：0-未翻译，1-翻译中，2-翻译完成，3-翻译失败',
ADD COLUMN translation_error VARCHAR(500) NOT NULL DEFAULT '' COMMENT '翻译错误信息',
ADD COLUMN last_translation_time DATETIME NULL COMMENT '最后翻译时间';
```

## 问题3：StoreOrderInfo实体类改造

### 现状分析
- 当前字段：id, mer_order_no, mer_id, product_id, product_name, image, attr_value_id, sku, price, pay_num, weight, volume, is_reply, is_receipt, create_time, update_time
- 缺少多语言商品名称字段

### 改造方案

#### 3.1 新增字段
```java
@ApiModelProperty(value = "用户提交询价时的语言：zh-中文，en-英文，ru-俄语，ar-阿拉伯语")
private String language;

@ApiModelProperty(value = "商品名称-原始语言（用户看到的语言）")
private String productNameOriginal;

@ApiModelProperty(value = "商品图片-原始语言（用户看到的图片）")
private String imageOriginal;
```

#### 3.2 删除字段
```java
// 删除以下电商相关字段
private Integer attrValueId;  // 规格值ID
private String sku;           // 商品SKU
private BigDecimal weight;    // 重量
private BigDecimal volume;    // 体积
private Boolean isReply;      // 是否评价
private Boolean isReceipt;    // 是否收货
```

#### 3.3 修改字段含义
```java
@ApiModelProperty(value = "询价数量")
private Integer payNum;  // 原名保持，但含义改为询价数量
```

#### 3.4 对应SQL
```sql
ALTER TABLE eb_store_order_info
ADD COLUMN language VARCHAR(10) NOT NULL DEFAULT 'zh' COMMENT '用户提交询价时的语言：zh-中文，en-英文，ru-俄语，ar-阿拉伯语',
ADD COLUMN product_name_original VARCHAR(200) NOT NULL DEFAULT '' COMMENT '商品名称-原始语言（用户看到的语言）',
ADD COLUMN image_original VARCHAR(500) NOT NULL DEFAULT '' COMMENT '商品图片-原始语言（用户看到的图片）',
DROP COLUMN attr_value_id,
DROP COLUMN sku,
DROP COLUMN weight,
DROP COLUMN volume,
DROP COLUMN is_reply,
DROP COLUMN is_receipt;

-- 修改字段注释
ALTER TABLE eb_store_order_info 
MODIFY COLUMN pay_num INT(11) NOT NULL DEFAULT 0 COMMENT '询价数量';
```

## 总结

### 改造的实体类
1. **StoreProductDescription** - 商品详情多语言支持
2. **ProductCategory** - 分类多语言支持
3. **StoreOrderInfo** - 询价单详情多语言快照

### 设计原则
1. 所有多语言字段统一命名规范：`字段名_语言代码`
2. 所有需要翻译的表都增加 `translation_status`、`translation_error`、`last_translation_time` 字段
3. 询价单详情保存用户看到的语言版本（快照机制）
4. 删除所有电商相关字段，简化数据结构
