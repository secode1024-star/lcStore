## 1. 商品管理模块改造

### 1.1 商品列表页面（list.vue）

**路由**: `/product/list`

**改造内容**:
1. 增加翻译状态列
2. 增加审核状态列
3. 增加多语言字段显示
4. 增加翻译进度查看功能
5. 增加重新翻译按钮
6. 删除库存、销量等电商字段

**表格列**:
| 列名 | 字段 | 说明 | 改造类型 |
|------|------|------|---------|
| 商品ID | id | - | 保留 |
| 商品图片 | image | 缩略图 | 保留 |
| 商品名称 | storeName | - | 保留 |
| 分类 | categoryName | - | 保留 |
| 价格 | price/priceUsd | 人民币/美元 | 改造（增加美元） |
| 上架状态 | isShow | 开关 | 保留 |
| **审核状态** | **auditStatus** | **标签** | **新增** |
| **翻译状态** | **translationStatus** | **标签+进度** | **新增** |
| 创建时间 | createTime | - | 保留 |
| 操作 | - | 编辑/删除/查看翻译 | 改造 |

**筛选条件**:
- 商品名称（搜索）
- 分类（下拉选择）
- 上架状态（全部/上架/下架）
- **审核状态（全部/待审核/通过/拒绝）** - 新增
- **翻译状态（全部/未翻译/翻译中/完成/失败）** - 新增

**新增功能按钮**:
1. **查看翻译进度** - 点击弹窗显示翻译详情
2. **重新翻译** - 翻译失败时可重新触发翻译

**翻译进度弹窗设计**:

**API对接**:
```javascript
// api/product.js
import request from '@/utils/request'

// 获取商品列表
export function getProductList(params) {
  return request({
    url: '/api/merchant/product/list',
    method: 'get',
    params
  })
}

// 获取翻译进度
export function getTranslationProgress(id) {
  return request({
    url: `/api/merchant/product/translation-progress/${id}`,
    method: 'get'
  })
}

// 重新翻译
export function retryTranslation(id) {
  return request({
    url: `/api/merchant/product/retry-translation/${id}`,
    method: 'post'
  })
}
```

### 1.2 商品添加页面（add.vue）

**路由**: `/product/add`

**改造内容**:
1. 删除库存、规格、积分等电商字段
2. 增加美元价格字段
3. 改造图片上传（轮播图+详情图分开）
4. 分类选择改为平台分类
5. 增加翻译说明提示

**表单字段**:

#### 基本信息
| 字段名 | 类型 | 必填 | 说明 | 改造类型 |
|--------|------|------|------|---------|
| 商品名称 | 文本 | 是 | 中文名称 | 保留 |
| 商品分类 | 下拉 | 是 | 平台分类 | 改造 |
| 商品简介 | 文本域 | 是 | 简短描述 | 保留 |
| 商品关键词 | 文本 | 否 | 逗号分隔 | 保留 |
| 商品主图 | 图片 | 是 | 单张 | 保留 |
| 轮播图 | 图片 | 是 | 多张（最多5张） | 保留 |
| **详情图** | **图片** | **否** | **多张（最多10张）** | **新增** |

#### 价格信息
| 字段名 | 类型 | 必填 | 说明 | 改造类型 |
|--------|------|------|------|---------|
| 人民币价格 | 数字 | 是 | 单位：元 | 保留 |
| **美元价格** | **数字** | **是** | **单位：美元** | **新增** |
| 人民币原价 | 数字 | 否 | 划线价 | 保留 |
| **美元原价** | **数字** | **否** | **划线价** | **新增** |

#### 商品详情
| 字段名 | 类型 | 必填 | 说明 | 改造类型 |
|--------|------|------|------|---------|
| 商品详情 | 富文本 | 是 | 详细描述 | 保留 |

#### 删除的字段
- ~~库存~~
- ~~销量~~
- ~~虚拟销量~~
- ~~赠送积分~~
- ~~成本价~~
- ~~会员价~~
- ~~邮费~~
- ~~规格~~
- ~~单位~~

**翻译说明提示**:
```
┌─────────────────────────────────────┐
│ ℹ️ 翻译说明                          │
├─────────────────────────────────────┤
│ 1. 点击"上架"按钮后，系统将自动翻译  │
│    商品内容为英文、俄语、阿拉伯语    │
│                                     │
│ 2. 翻译内容包括：                    │
│    - 商品名称、简介、关键词、详情    │
│    - 商品主图、轮播图、详情图        │
│                                     │
│ 3. 翻译完成后商品将自动上架          │
│                                     │
│ 4. 如果翻译失败，商品将保持下架状态  │
│    您可以在商品列表中重新翻译        │
```

### 1.3 商品编辑页面（edit.vue）

**路由**: `/product/edit/:id`

**改造内容**:
1. 与添加页面类似的字段改造
2. 增加编辑限制提示（已上架商品需先下架）
3. 显示当前翻译状态
4. 显示审核状态

**编辑限制提示**:
```
┌─────────────────────────────────────┐
│ ⚠️ 编辑提示                          │
├─────────────────────────────────────┤
│ 该商品当前状态：已上架               │
│                                     │
│ 如需编辑商品信息，请先下架商品。     │
│ 编辑完成后重新上架将触发翻译。       │
│                                     │
│ [下架商品]                           │
└─────────────────────────────────────┘
```

**API对接**:
```javascript
// 获取商品详情
export function getProductDetail(id) {
  return request({
    url: `/api/merchant/product/detail/${id}`,
    method: 'get'
  })
}

// 更新商品
export function updateProduct(id, data) {
  return request({
    url: `/api/merchant/product/update/${id}`,
    method: 'put',
    data
  })
}

// 下架商品
export function offSaleProduct(id) {
  return request({
    url: `/api/merchant/product/off-sale/${id}`,
    method: 'put'
  })
}
```
