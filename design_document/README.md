## 📋 设计方案概览

### 项目目标
将现有的CRMEB Java电商系统改造为多语言询价平台，支持中文、英文、俄语、阿拉伯语四种语言。

### 核心功能
1. **多语言支持** - 商品、分类、系统配置的多语言翻译
2. **图片翻译** - 使用大模型API翻译商品图片
3. **询价系统** - 替代原有的订单交易系统
4. **意向清单** - 替代购物车，仅登录用户可用
5. **商品审核** - 商品翻译完成后需平台审核

### 技术栈
- **后端框架**: Spring Boot 2.2.6
- **ORM框架**: MyBatis-Plus
- **数据库**: MySQL 8.0.33
- **缓存**: Redis
- **对象存储**: 阿里云OSS
- **AI翻译**: 大模型API（通义千问VL）

### 开发规范
- 严格遵循《阿里巴巴Java开发手册（嵩山版）》
- 数据库设计符合阿里规范
- 代码注释清晰，命名规范

## 🔄 改造范围

### 数据库层
- 商品表增加多语言字段
- 分类表增加多语言字段
- 订单表改造为询价单表
- 购物车表改造为意向清单表
- 新增图片翻译记录表
- 删除支付、物流、优惠券等电商相关表

### 业务逻辑层
- 商品上架流程：上架 → 翻译 → 审核 → 展示
- 询价流程：用户询价 → 翻译成中文 → 平台处理
- 翻译服务：文本翻译 + 图片翻译
- 异步任务管理：翻译任务监控和重试

### API接口层
- C端接口：根据语言动态返回多语言内容
- 商家端接口：商品管理、翻译状态查询
- 平台端接口：询价管理、商品审核、翻译成本统计

## 📊 设计决策

### 已确认的关键决策
1. **用户系统** - 支持游客和登录用户，意向清单仅登录用户可用
2. **翻译触发** - 商品上架时自动触发翻译
3. **翻译失败** - 阻止上架，商家需重试
4. **商品编辑** - 已上架商品必须先下架才能编辑
5. **询价状态** - 待处理/已处理/已废弃
6. **价格显示** - 同时显示美元和人民币
7. **翻译存储** - 使用字段方式，不用单独的翻译关联表
8. **图片存储** - 阿里云OSS，按语言分目录存储
9. **翻译缓存** - 数据库缓存 + Redis二级缓存
10. **异步任务** - 使用@Async注解，Redis记录任务状态
