## 🔴 问题清单

### 问题1：数据库设计 - 缺少国家表

**问题描述**:
- 前端设计中提到了国家选择功能（询价表单、用户信息）
- 但数据库设计中没有国家表（eb_country）
- 国家数据需要支持多语言（中英俄阿）

**影响范围**:
- 询价表单的国家选择
- 用户默认国家设置
- 平台端询价统计（按国家统计）

**建议方案**:
创建国家表：
```sql
CREATE TABLE `eb_country` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `code` VARCHAR(10) NOT NULL COMMENT '国家代码（ISO 3166-1）',
  `name_zh` VARCHAR(100) NOT NULL COMMENT '中文名称',
  `name_en` VARCHAR(100) NOT NULL COMMENT '英文名称',
  `name_ru` VARCHAR(100) NOT NULL DEFAULT '' COMMENT '俄语名称',
  `name_ar` VARCHAR(100) NOT NULL DEFAULT '' COMMENT '阿拉伯语名称',
  `sort` INT NOT NULL DEFAULT 0 COMMENT '排序',
  `is_hot` TINYINT NOT NULL DEFAULT 0 COMMENT '是否热门国家（0-否，1-是）',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_code` (`code`),
  KEY `idx_sort` (`sort`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='国家表';
```

**优先级**: 高
