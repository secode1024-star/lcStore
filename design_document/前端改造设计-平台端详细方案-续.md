## 5. 商家管理模块（merchant）

### 5.1 商家列表页面（list.vue）
**路由**: `/merchant/list`

**功能**:
- 商家列表展示
- 筛选条件：商家名称、商家状态
- 分页
- 查看详情按钮
- 启用/禁用商家按钮
- 添加商家按钮

**表格列**:
| 列名 | 字段 | 说明 |
|------|------|------|
| 商家ID | merId | - |
| 商家名称 | merName | 可点击查看详情 |
| 商家账号 | account | - |
| 联系人 | linkman | - |
| 联系电话 | phone | - |
| 商家状态 | status | 开关（正常/禁用） |
| 商品总数 | productCount | - |
| 上架商品数 | onSaleProductCount | - |
| 创建时间 | createTime | - |
| 操作 | - | 查看详情、启用/禁用 |

**API对接**:
```javascript
// api/merchant.js
import request from '@/utils/request'

// 获取商家列表
export function getMerchantList(params) {
  return request({
    url: '/api/platform/merchant/list',
    method: 'get',
    params
  })
}

// 更新商家状态
export function updateMerchantStatus(id, data) {
  return request({
    url: `/api/platform/merchant/update-status/${id}`,
    method: 'put',
    data
  })
}

// 添加商家
export function addMerchant(data) {
  return request({
    url: '/api/platform/merchant/add',
    method: 'post',
    data
  })
}
```

## 10. 通用组件设计

### 10.1 翻译状态标签组件（TranslationStatusTag.vue）

**用途**: 显示翻译状态的标签

**Props**:
```javascript
{
  status: {
    type: Number,
    required: true
    // 0-未翻译，1-翻译中，2-翻译完成，3-翻译失败
  }
}
```

**实现**:
```vue
<template>
  <el-tag :type="tagType">{{ statusText }}</el-tag>
</template>

<script>
export default {
  name: 'TranslationStatusTag',
  props: {
    status: {
      type: Number,
      required: true
    }
  },
  computed: {
    statusText() {
      const statusMap = {
        0: '未翻译',
        1: '翻译中',
        2: '翻译完成',
        3: '翻译失败'
      }
      return statusMap[this.status] || '未知'
    },
    tagType() {
      const typeMap = {
        0: 'info',
        1: 'warning',
        2: 'success',
        3: 'danger'
      }
      return typeMap[this.status] || 'info'
    }
  }
}
</script>
```

      <div dir="rtl">{{ content.ar }}</div>
    </el-tab-pane>
