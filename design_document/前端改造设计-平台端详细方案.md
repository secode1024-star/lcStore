### 需要新增的模块和页面

#### 1. 询价管理模块（inquiry）

##### 1.1 询价单列表页面（list.vue）
**路由**: `/inquiry/list`

**功能**:
- 询价单列表展示（表格）
- 筛选条件：询价单号、商家、询价状态、用户语言、国家、时间范围
- 分页
- 查看详情按钮
- 更新状态按钮（待处理→已处理/已废弃）
- 导出功能（可选）

**表格列**:
| 列名 | 字段 | 说明 |
|------|------|------|
| 询价单号 | inquiryNo | 可点击查看详情 |
| 询价状态 | inquiryStatus | 标签显示（待处理/已处理/已废弃） |
| 商品总数 | totalNum | - |
| 联系人 | realName | 中文翻译 |
| 联系电话 | userPhone | - |
| 联系邮箱 | userEmail | - |
| 国家 | country | 中文翻译 |
| 用户语言 | userLanguage | zh/en/ru/ar |
| 涉及商家数 | merchantCount | - |
| 提交时间 | createTime | - |
| 处理时间 | processTime | - |
| 操作 | - | 查看详情、更新状态 |

**API对接**:
```javascript
// api/inquiry.js
import request from '@/utils/request'

// 获取询价单列表
export function getInquiryList(params) {
  return request({
    url: '/api/platform/inquiry/list',
    method: 'get',
    params
  })
}

// 更新询价单状态
export function updateInquiryStatus(inquiryNo, data) {
  return request({
    url: `/api/platform/inquiry/update-status/${inquiryNo}`,
    method: 'put',
    data
  })
}
```

#### 4. 分类管理模块（category）

##### 4.1 分类管理页面（index.vue）
**路由**: `/category/index`

**功能**:
- 分类树形展示
- 添加分类
- 编辑分类
- 删除分类
- 显示/隐藏分类
- 查看多语言翻译

**页面布局**:
```
┌─────────────────────────────────────┐
│ 分类管理                             │
│ [添加顶级分类]                       │
├─────────────────────────────────────┤
│ 分类树形表格                         │
│ ├─ 电子产品 [编辑][删除][添加子分类]│
│ │  ├─ 手机 [编辑][删除]             │
│ │  └─ 电脑 [编辑][删除]             │
│ ├─ 服装 [编辑][删除][添加子分类]    │
│ │  ├─ 男装 [编辑][删除]             │
│ │  └─ 女装 [编辑][删除]             │
└─────────────────────────────────────┘
```

**表格列**:
| 列名 | 字段 | 说明 |
|------|------|------|
| 分类名称 | name | 树形展示 |
| 英文名称 | nameEn | - |
| 俄语名称 | nameRu | - |
| 阿拉伯语名称 | nameAr | - |
| 图标 | icon | - |
| 排序 | sort | - |
| 显示状态 | isShow | 开关 |
| 翻译状态 | translationStatus | 标签 |
| 操作 | - | 编辑/删除/添加子分类 |

**弹窗表单**:
- 分类名称（必填）
- 分类图标（可选）
- 排序（默认0）
- 显示状态（默认显示）

**API对接**:
```javascript
// api/category.js
import request from '@/utils/request'

// 获取分类列表
export function getCategoryList(params) {
  return request({
    url: '/api/platform/category/list',
    method: 'get',
    params
  })
}

// 添加分类
export function addCategory(data) {
  return request({
    url: '/api/platform/category/add',
    method: 'post',
    data
  })
}

// 更新分类
export function updateCategory(id, data) {
  return request({
    url: `/api/platform/category/update/${id}`,
    method: 'put',
    data
  })
}

// 删除分类
export function deleteCategory(id) {
  return request({
    url: `/api/platform/category/delete/${id}`,
    method: 'delete'
  })
}
```
