## 2. 翻译重试策略

### 2.1 重试策略设计

**自动重试**:
- 最多重试3次
- 重试间隔5秒
- 只对网络错误、超时错误进行重试
- 对于业务错误（如API Key无效）不重试

**手动重试**:
- 自动重试失败后，商家可在商品列表页手动触发重试
- 手动重试不限次数
- 每次手动重试都会记录

**失败处理**:
- 记录失败原因和错误信息
- 商品保持下架状态
- 发送站内消息通知商家

### 2.2 重试逻辑实现

```java
package com.zbkj.service.service.impl;

import com.zbkj.service.config.TranslationConfig;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

/**
 * 翻译重试服务
 */
@Slf4j
@Service
public class TranslationRetryService {

    @Autowired
    private TranslationConfig translationConfig;

    /**
     * 执行翻译（带重试）
     * @param task 翻译任务
     * @return 翻译结果
     */
    public <T> T executeWithRetry(TranslationTask<T> task) {
        TranslationConfig.ProviderConfig config = translationConfig.getCurrentProvider();
        int maxRetries = config.getMaxRetries();
        int retryInterval = config.getRetryInterval();
        
        Exception lastException = null;
        
        for (int i = 0; i <= maxRetries; i++) {
            try {
                if (i > 0) {
                    log.info("翻译重试第{}次", i);
                    Thread.sleep(retryInterval);
                }
                
                return task.execute();
                
            } catch (Exception e) {
                lastException = e;
                
                // 判断是否可重试
                if (!isRetryable(e)) {
                    log.error("翻译失败，不可重试：{}", e.getMessage());
                    throw new RuntimeException("翻译失败：" + e.getMessage(), e);
                }
                
                if (i < maxRetries) {
                    log.warn("翻译失败，将进行重试：{}", e.getMessage());
                } else {
                    log.error("翻译失败，已达到最大重试次数", e);
                }
            }
        }
        
        throw new RuntimeException("翻译失败，已重试" + maxRetries + "次", lastException);
    }

    /**
     * 判断异常是否可重试
     */
    private boolean isRetryable(Exception e) {
        String message = e.getMessage();
        if (message == null) {
            return false;
        }
        
        // 网络错误、超时错误可重试
        if (message.contains("timeout") || 
            message.contains("connect") || 
            message.contains("network") ||
            message.contains("503") ||
            message.contains("502")) {
            return true;
        }
        
        // API Key错误、参数错误不可重试
        if (message.contains("api key") || 
            message.contains("invalid") || 
            message.contains("401") ||
            message.contains("403")) {
            return false;
        }
        
        // 其他错误默认可重试
        return true;
    }

    /**
     * 翻译任务接口
     */
    @FunctionalInterface
    public interface TranslationTask<T> {
        T execute() throws Exception;
    }
}
```

### 3.1 站内消息通知

```java
/**
 * 翻译失败后发送站内消息
 */
public void sendTranslationFailureMessage(Long productId, String errorMessage) {
    // 获取商品信息
    StoreProduct product = storeProductService.getById(productId);
    if (product == null) {
        return;
    }
    
    // 创建消息
    SystemMessage message = new SystemMessage();
    message.setMerId(product.getMerId());
    message.setType(3); // 翻译通知

    message.setContent(String.format(
        "您的商品"%s"翻译失败。\n\n" +
        "商品ID：%d\n" +
        "失败原因：%s\n\n" +
        "您可以在商品列表中点击"重新翻译"按钮重试。",
        product.getStoreName(),
        productId,
        errorMessage
    ));
    message.setIsRead(0);
    message.setCreateTime(new Date());
    
    systemMessageService.save(message);
}
```

## 4. 翻译进度监控

### 4.1 Redis状态管理

```java
/**
 * 翻译进度Redis Key
 */
public class TranslationRedisKey {
    private static final String PREFIX = "translation:progress:";
    
    public static String getProgressKey(Long productId) {
        return PREFIX + productId;
    }
}

/**
 * 翻译进度信息
 */
@Data
public class TranslationProgress {
    private Long productId;
    private Integer status; // 0-未开始，1-进行中，2-完成，3-失败
    private Integer totalSteps; // 总步骤数
    private Integer completedSteps; // 已完成步骤数
    private String currentStep; // 当前步骤描述
    private String errorMessage; // 错误信息
    private Date startTime; // 开始时间
    private Date endTime; // 结束时间
}

/**
 * 更新翻译进度
 */
public void updateProgress(Long productId, String step, int completed, int total) {
    String key = TranslationRedisKey.getProgressKey(productId);
    
    TranslationProgress progress = new TranslationProgress();
    progress.setProductId(productId);
    progress.setStatus(1); // 进行中
    progress.setTotalSteps(total);
    progress.setCompletedSteps(completed);
    progress.setCurrentStep(step);
    
    // 保存到Redis，过期时间1小时
    redisUtil.set(key, JSON.toJSONString(progress), 3600);
}
```

## 5. 翻译成本记录

### 5.1 成本记录表

```sql
CREATE TABLE `eb_translation_cost` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `mer_id` INT NOT NULL DEFAULT 0 COMMENT '商家ID（0-平台）',
  `product_id` BIGINT UNSIGNED DEFAULT NULL COMMENT '商品ID',
  `translation_type` TINYINT NOT NULL COMMENT '翻译类型（1-文本，2-图片）',
  `content_type` VARCHAR(50) NOT NULL DEFAULT '' COMMENT '内容类型（product_name/product_desc/product_image等）',
  `source_language` VARCHAR(10) NOT NULL DEFAULT 'zh' COMMENT '源语言',
  `target_language` VARCHAR(10) NOT NULL DEFAULT '' COMMENT '目标语言',
  `tokens` INT NOT NULL DEFAULT 0 COMMENT 'Token数量',
  `cost` DECIMAL(10, 4) NOT NULL DEFAULT 0.0000 COMMENT '成本（元）',
  `provider` VARCHAR(20) NOT NULL DEFAULT '' COMMENT '翻译服务提供商',
  `model` VARCHAR(50) NOT NULL DEFAULT '' COMMENT '模型名称',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_mer_id` (`mer_id`),
  KEY `idx_product_id` (`product_id`),
  KEY `idx_create_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='翻译成本记录表';
```

### 5.2 成本记录服务

```java
/**
 * 记录翻译成本
 */
public void recordCost(Long productId, Integer merId, String translationType, 
                       String contentType, String targetLang, Integer tokens) {
    if (!translationConfig.getCost().getEnabled()) {
        return;
    }
    
    // 计算成本
    Double price = "text".equals(translationType) 
        ? translationConfig.getCost().getTextPrice()
        : translationConfig.getCost().getImagePrice();
    Double cost = (tokens / 1000.0) * price;
    
    // 保存记录
    TranslationCost record = new TranslationCost();
    record.setMerId(merId);
    record.setProductId(productId);
    record.setTranslationType("text".equals(translationType) ? 1 : 2);
    record.setContentType(contentType);
    record.setSourceLanguage("zh");
    record.setTargetLanguage(targetLang);
    record.setTokens(tokens);
    record.setCost(new BigDecimal(cost));
    record.setProvider(translationConfig.getProvider());
    record.setModel(translationConfig.getCurrentProvider().getModel());
    record.setCreateTime(new Date());
    
    translationCostService.save(record);
}
```

## 9. 使用文档

### 9.1 配置步骤

1. **获取API Key**
   - 通义千问：访问 https://dashscope.aliyun.com/ 注册并获取API Key
   - OpenAI：访问 https://platform.openai.com/ 注册并获取API Key

2. **配置环境变量**
   ```bash
   export QIANWEN_API_KEY=your_api_key
   ```

3. **修改配置文件**
   ```yaml
   translation:
     provider: qianwen  # 选择翻译服务商
   ```

4. **测试翻译功能**
   - 上传一个商品并点击上架
   - 查看翻译进度
   - 检查翻译结果

### 9.2 故障排查

**问题1：翻译一直失败**
- 检查API Key是否正确
- 检查网络连接
- 查看错误日志

**问题2：翻译速度慢**
- 检查网络延迟
- 考虑增加超时时间
- 考虑切换翻译服务商

**问题3：成本过高**
- 检查是否启用了缓存
- 优化翻译内容（减少重复翻译）
- 考虑使用更便宜的模型

## 10. 注意事项

1. **API Key安全**: 不要将API Key提交到代码仓库，使用环境变量
2. **成本控制**: 定期检查翻译成本，设置预算告警
3. **缓存策略**: 相同内容不要重复翻译，充分利用缓存
4. **错误处理**: 记录详细的错误日志，方便排查问题
5. **服务降级**: 翻译服务不可用时，允许商品先上架，后续补充翻译
6. **监控告警**: 设置翻译失败率告警，及时发现问题
