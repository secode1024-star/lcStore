## 2. 站内消息模块（新增）

### 2.1 消息列表页面（list.vue）

**路由**: `/message/list`

**功能**:
- 消息列表展示
- 筛选条件：消息类型、已读/未读
- 分页
- 标记已读/未读
- 删除消息
- 查看详情

**消息类型**:
1. **系统通知** - 系统公告、维护通知等
2. **商品审核** - 商品审核通过/拒绝通知
3. **翻译通知** - 翻译完成/失败通知

**表格列**:
| 列名 | 字段 | 说明 |
|------|------|------|
| 消息类型 | type | 标签显示 |
| 消息标题 | title | 可点击查看详情 |
| 消息摘要 | summary | 截取前50字 |
| 已读状态 | isRead | 标签（未读/已读） |
| 发送时间 | createTime | - |
| 操作 | - | 查看详情、标记已读、删除 |

**页面布局**:
```
┌─────────────────────────────────────┐
│ 站内消息                             │
│ [全部标记已读] [删除已读消息]        │
├─────────────────────────────────────┤
│ 筛选条件：                           │
│ 消息类型：[全部▼] 状态：[全部▼]     │
├─────────────────────────────────────┤
│ 消息列表                             │
│ ┌─────────────────────────────────┐ │
│ │ 🔴 [系统通知] 系统维护通知       │ │
│ │    系统将于...                   │ │
│ │    2026-05-18 10:00             │ │
│ │    [查看] [标记已读] [删除]      │ │
│ ├─────────────────────────────────┤ │
│ │ ⚪ [商品审核] 商品审核通过        │ │
│ │    您的商品"测试商品"已审核通过  │ │
│ │    2026-05-17 15:30             │ │
│ │    [查看] [标记未读] [删除]      │ │
│ ├─────────────────────────────────┤ │
│ │ 🔴 [翻译通知] 商品翻译完成       │ │
│ │    您的商品"测试商品"翻译完成    │ │
│ │    2026-05-17 14:20             │ │
│ │    [查看] [标记已读] [删除]      │ │
│ └─────────────────────────────────┘ │
│                                     │
│ [分页组件]                           │
└─────────────────────────────────────┘
```

**未读消息提醒**:
- 顶部导航栏显示未读消息数量（红点或数字）
- 点击消息图标弹出最近5条未读消息
- 点击"查看全部"跳转到消息列表页面

**API对接**:
```javascript
// api/message.js
import request from '@/utils/request'

// 获取消息列表
export function getMessageList(params) {
  return request({
    url: '/api/merchant/message/list',
    method: 'get',
    params
  })
}

// 获取未读消息数量
export function getUnreadCount() {
  return request({
    url: '/api/merchant/message/unread-count',
    method: 'get'
  })
}

// 标记已读
export function markAsRead(id) {
  return request({
    url: `/api/merchant/message/mark-read/${id}`,
    method: 'put'
  })
}

// 全部标记已读
export function markAllAsRead() {
  return request({
    url: '/api/merchant/message/mark-all-read',
    method: 'put'
  })
}

// 删除消息
export function deleteMessage(id) {
  return request({
    url: `/api/merchant/message/delete/${id}`,
    method: 'delete'
  })
}
```

## 5. 通用组件设计

### 5.1 翻译进度组件（TranslationProgress.vue）

**用途**: 显示商品翻译进度的弹窗组件

**Props**:
```javascript
{
  productId: {
    type: Number,
    required: true
  },
  visible: {
    type: Boolean,
    default: false
  }
}
```

**实现**:
```vue
<template>
  <el-dialog
    title="翻译进度详情"
    :visible.sync="dialogVisible"
    width="600px"
    @close="handleClose"
  >
    <div v-loading="loading">
      <!-- 基本信息 -->
      <div class="info-section">
        <p><strong>商品名称：</strong>{{ productInfo.storeName }}</p>
        <p><strong>翻译状态：</strong>
          <translation-status-tag :status="productInfo.translationStatus" />
        </p>
        <p><strong>最后翻译时间：</strong>{{ productInfo.lastTranslationTime }}</p>
      </div>

      <!-- 文本翻译进度 -->
      <div class="progress-section">
        <h4>文本翻译进度</h4>
        <el-progress
          :percentage="textProgress"
          :status="textProgressStatus"
        />
        <ul class="progress-list">
          <li v-for="item in textTranslations" :key="item.field">
            <i :class="item.icon"></i>
            {{ item.label }}：{{ item.status }}
          </li>
        </ul>
      </div>

      <!-- 图片翻译进度 -->
      <div class="progress-section">
        <h4>图片翻译进度</h4>
        <el-progress
          :percentage="imageProgress"
          :status="imageProgressStatus"
        />
        <ul class="progress-list">
          <li v-for="item in imageTranslations" :key="item.id">
            <i :class="item.icon"></i>
            {{ item.label }}：{{ item.status }}
          </li>
        </ul>
      </div>

      <!-- 翻译成本 -->
      <div class="cost-section">
        <h4>翻译成本统计</h4>
        <p>文本翻译Token：{{ costInfo.textTokens }}</p>
        <p>图片翻译Token：{{ costInfo.imageTokens }}</p>
        <p>总成本：¥{{ costInfo.totalCost }}</p>
      </div>

      <!-- 错误信息 -->
      <div v-if="errorMessage" class="error-section">
        <el-alert
          type="error"
          :title="errorMessage"
          :closable="false"
        />
      </div>
    </div>

    <span slot="footer" class="dialog-footer">
      <el-button @click="handleClose">关闭</el-button>
      <el-button
        v-if="canRetry"
        type="primary"
        @click="handleRetry"
      >
        重新翻译
      </el-button>
    </span>
  </el-dialog>
</template>

<script>
import { getTranslationProgress, retryTranslation } from '@/api/product'
import TranslationStatusTag from '@/components/TranslationStatusTag'

export default {
  name: 'TranslationProgress',
  components: { TranslationStatusTag },
  props: {
    productId: {
      type: Number,
      required: true
    },
    visible: {
      type: Boolean,
      default: false
    }
  },
  data() {
    return {
      loading: false,
      productInfo: {},
      textTranslations: [],
      imageTranslations: [],
      costInfo: {},
      errorMessage: ''
    }
  },
  computed: {
    dialogVisible: {
      get() {
        return this.visible
      },
      set(val) {
        this.$emit('update:visible', val)
      }
    },
    textProgress() {
      // 计算文本翻译进度百分比
      const total = this.textTranslations.length
      const completed = this.textTranslations.filter(t => t.completed).length
      return total > 0 ? Math.round((completed / total) * 100) : 0
    },
    imageProgress() {
      // 计算图片翻译进度百分比
      const total = this.imageTranslations.length
      const completed = this.imageTranslations.filter(t => t.completed).length
      return total > 0 ? Math.round((completed / total) * 100) : 0
    },
    textProgressStatus() {
      return this.textProgress === 100 ? 'success' : null
    },
    imageProgressStatus() {
      return this.imageProgress === 100 ? 'success' : null
    },
    canRetry() {
      return this.productInfo.translationStatus === 3 // 翻译失败
    }
  },
  watch: {
    visible(val) {
      if (val) {
        this.fetchData()
      }
    }
  },
  methods: {
    async fetchData() {
      this.loading = true
      try {
        const res = await getTranslationProgress(this.productId)
        this.productInfo = res.data.productInfo
        this.textTranslations = res.data.textTranslations
        this.imageTranslations = res.data.imageTranslations
        this.costInfo = res.data.costInfo
        this.errorMessage = res.data.errorMessage
      } catch (error) {
        this.$message.error('获取翻译进度失败')
      } finally {
        this.loading = false
      }
    },
    handleClose() {
      this.dialogVisible = false
    },
    async handleRetry() {
      try {
        await retryTranslation(this.productId)
        this.$message.success('已提交重新翻译请求')
        this.handleClose()
        this.$emit('retry-success')
      } catch (error) {
        this.$message.error('重新翻译失败')
      }
    }
  }
}
</script>

<style scoped>
.info-section,
.progress-section,
.cost-section,
.error-section {
  margin-bottom: 20px;
}

.progress-list {
  list-style: none;
  padding: 0;
  margin-top: 10px;
}

.progress-list li {
  padding: 5px 0;
}

.progress-list i {
  margin-right: 5px;
}
</style>
```
